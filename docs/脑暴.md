3. 76° 是怎么来的？

这个就开始进入运动学分析了。

假设要计算肘关节角度：

肩
 \
  肘
   \
    腕

实际上就是计算：

肩 → 肘 → 腕

三个点形成的夹角。

数学上：

A = 肩
B = 肘
C = 腕
向量 BA = A - B
向量 BC = C - B
angle = arccos(
    dot(BA, BC)
    /
    (|BA| × |BC|)
)

得到：

76°

然后把 76° 画到视频上。

所以：

AI负责“找到身体”，数学负责“算动作”。

4. “过肩 ✓”也是规则计算出来的

这个更有意思。

例如羽毛球挥拍时，可以定义：

手腕 Y < 肩膀 Y

因为图像坐标系通常是：

       0
       ↓
       Y
       
肩膀 Y = 420
手腕 Y = 310

所以：

310 < 420

意味着手腕在肩膀上方。

但这里有一个非常关键的技术边界：

单靠手机摄像头，不能真正测出“肌肉有没有发力”。

摄像头能看到的是动作结果；肌电（EMG）才能直接看到肌肉的电活动。

# 补充：体态分析模块（Posture Engine）

## 定位：体态是“因”，动作是“果”

- 体态分析回答更上游的问题：身体本身的结构偏差是什么
- 结构偏差会污染动作分析结果（如骨盆前倾者深蹲“看起来躯干前倾”，不是动作错误，是结构问题）
- 因此体态分析先做，反而让动作分析更准

## 为什么适合做产品第一入口

| 维度 | 动作分析 | 体态分析 |
| --- | --- | --- |
| 用户门槛 | 换装、做动作 | 拍两张照（正面+侧面） |
| 首次价值感知 | 练完出报告 | 30秒出诊断报告 |
| 传播性 | 一般 | 强（前后对比图） |
| 与计划的关系 | 计划内执行环节 | 直接驱动计划生成 |

## 产品闭环

体态评估（正+侧两照）→ 诊断报告（问题+严重度）→ 纠正计划（放松+激活+整合）→ 每日跟练（复用动作引擎）→ 复测对比（4-8周角度变化）→ 回到评估

- 复测对比是留存关键：前后肩线/骨盆角度并排对比，数字变化可见

## 技术实现：静态版 Pose 分析

- 同一个 Pose 模型（MediaPipe 33点），不新增模型，只新增 Posture Feature Engine
- 差异：动作分析取动态时序（角度曲线/速度/轨迹），体态分析取静态对齐（偏移/对称/夹角）
- 单目无深度：偏移量需归一化为比例（如耳-肩偏移÷躯干长度），不能直接量像素

| 视角 | 关键特征 | 计算方式 | 指向问题 |
| --- | --- | --- | --- |
| 侧面 | 耳-肩水平偏移 | 耳垂与肩峰水平距离÷躯干长度 | 头前引 |
| 侧面 | 肩-髋水平偏移 | 肩峰与髂嵴水平距离（归一化） | 圆肩/驼背 |
| 侧面 | 髋-膝-踝夹角 | 三点角度 | 膝超伸、骨盆前倾 |
| 正面 | 双肩高度差 | 左右肩峰y差 | 高低肩 |
| 正面 | C7垂线偏移 | 脊柱上段相对骨盆中线偏移 | 脊柱侧弯（提示就医） |
| 正面 | 膝间距/踝间距 | 膝、踝水平偏移差 | X/O型腿 |

## 核心护城河：体态问题 → 肌肉失衡 → 纠正动作映射库

| 体态问题 | 紧张肌群（放松） | 无力肌群（激活） | 纠正动作示例 |
| --- | --- | --- | --- |
| 头前引 | 上斜方肌、肩胛提肌、胸锁乳突肌 | 深层颈屈肌 | 下巴后缩、门框胸拉伸 |
| 圆肩（上交叉） | 胸大肌/小肌、上斜方肌 | 中下斜方、菱形肌、前锯肌 | YTW、墙天使、弹力带划船 |
| 骨盆前倾（下交叉） | 髂腰肌、竖脊肌、股直肌 | 腹肌、臀大肌 | 臀桥、死虫式、髂腰肌拉伸 |
| 骨盆后倾 | 腘绳肌、臀肌 | 髂腰肌、下背伸肌 | 鸟狗式、髋屈肌激活 |
| 高低肩 | 高侧斜方肌上束 | 双侧中下斜方肌 | 单侧斜方拉伸、YTW |
| 膝超伸 | 腓肠肌、股直肌 | 臀大肌、核心 | 臀桥、小腿拉伸 |
| X型腿 | 内收肌、髂胫束 | 臀中肌 | 蚌式开合、内收肌拉伸 |
| O型腿 | 髋外旋肌群 | 内收肌、臀中肌 | 夹腿训练、臀桥 |

## 计划生成逻辑（Plan Engine）

1. 模板组合：每问题 = 放松2 + 激活2 + 整合1，每天10-15分钟
2. 严重度分级：轻（每天1组）/ 中（加容量）/ 重（提示先就医评估）
3. 多问题排序（地基顺序）：骨盆 → 胸椎 → 肩颈
4. 复测节奏：4周首测、8周对比，输出角度变化曲线

## MVP 建议

- 范围：2张照片 → 体态报告（5类常见问题×严重度）→ 2周纠正计划
- 复用：与动作分析共用 Pose Engine，新增 Posture Feature / Rule / Plan 三模块
- 传播钩子：报告叠加“理想体态轮廓线”，偏差区域标红，一张图就是分享素材

# 深化设计：映射库 14 问题 + 严重度阈值 + 报告 UI

## 映射库总览（5 区 14 项）

头颈区：头前引、颈曲变直
肩胛区：圆肩（上交叉）、翼状肩胛、高低肩
脊柱区：胸椎后凸（驼背）、平背、脊柱侧弯
骨盆区：骨盆前倾（下交叉）、骨盆后倾
下肢区：膝超伸、X型腿、O型腿、长短腿（功能性）

失衡结构统一为「紧张→放松 / 无力→激活」，纠正动作示例见上文表格。

## 严重度阈值表（归一化特征，可复测）

| 问题 | 测量特征 | 正常 | 轻度 | 中度 | 重度 |
| --- | --- | --- | --- | --- | --- |
| 头前引 | 耳-肩偏移÷躯干长 | <0.15 | 0.15-0.25 | 0.25-0.35 | >0.35 |
| 圆肩 | 肩-耳前移÷躯干长 | <0.10 | 0.10-0.18 | 0.18-0.28 | >0.28 |
| 高低肩 | 双肩峰高度差 | <0.5cm | 0.5-1.5cm | 1.5-3cm | >3cm |
| 骨盆前倾 | 骨盆前倾角 | <10° | 10-15° | 15-25° | >25° |
| 膝超伸 | 膝过伸角 | <3° | 3-7° | 7-12° | >12° |

## 分级联动规则

| 分级 | 报告颜色 | 训练计划 | 附加 |
| --- | --- | --- | --- |
| 轻度 | 黄 | 每日1组纠正（10-15min） | 日常姿势提醒 |
| 中度 | 橙 | 每日1组+拉伸时长加倍 | 每周2次泡沫轴 |
| 重度 | 红 | 仅低风险放松动作 | 就医/物理治疗提示 |

总分算法：100 起步，轻度扣8 / 中度扣15 / 重度扣25，下限 30，四舍五入。

## 报告 UI 结构（手机端）

自上而下：
1. 顶部导航：返回 / 标题「体态报告」/ 复测
2. Hero 区：总分环（体态健康分）+ 风险等级 + 问题数 + 较上次分差
3. 关键指标卡 ×2：最严重的两个问题的实测值 + 分级（如 EAR 0.31 中度）
4. 问题清单（按严重度排序）：卡片 = 问题名 + 实测值 + 严重度标签，展开显示「紧张→放松 / 无力→激活 / 动作」
5. CTA：生成 2 周纠正计划（全宽主按钮）
6. 复测行：下次复测倒计时 + 对比上次报告入口

设计决策：总分+热区图负责「一眼看懂」，卡片负责「钻细节」，底部 CTA 直接衔接计划生成，评估到开练一次点击。
