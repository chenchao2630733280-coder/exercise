# 训迹 · 产品路线图

> 本文件是产品的**单一真源路线图**，整合自 `脑暴.md`（推导/讨论）与 `AI健身教练-产品设计总文档.md`（结论/规则）。
> 当前代码（`index.html` / `js/` / `server.js`）为 **Phase Pre-0**：3D 动作浏览工具，本路线图是其演进参考。

---

## 1. 一句话定位

**用手机摄像头，把用户变成"看得见自己身体"的人 —— 先诊断体态，再给针对性训练计划，练的时候实时纠错、自动计数、生成可对比的成长报告。**

三层递进：

| 层 | 回答 | 核心技术 |
| --- | --- | --- |
| Pose 模型 | 身体在哪里 | MediaPipe Pose 33 点 |
| 规则引擎 | 动作/体态对不对 | Feature Engine + Rule Engine |
| LLM 教练 | 怎么告诉用户 | 自然语言生成建议 |

**三分离原则**：Pose 找身体、规则判对错、LLM 说话。三层不要混。

## 4. 分类体系升级（Phase 0 当前任务）

### 4.1 当前问题

- `SIDE_GROUPS` 是 9 个合并大组（胸/背/肩/手臂/核心/臀部/腿部/心肺/拉伸），不是用户视角的 16 个一级分类
- 没有"二级展开"
- 用户实际截图（训记 App）显示 16 个一级（大类：胸/背/腿/肩/前锯肌/斜方肌/二头/三头/小腿/前臂/颈部/臀部/功能性/核心稳定/腹部/拉伸），且每个一级下挂二级子分类（如胸 → 上胸/中下胸）

### 4.2 双轨对齐策略（已选）

一级分类（侧栏） = 截图视角（16 大类，按解剖部位），保证 UI 与截图一致；
二级分类（子项） = 脑暴文档肌肉失衡映射（紧张→放松 / 无力→激活）。

| 一级（截图） | 二级（脑暴映射） | 主肌群 muscle_key |
| --- | --- | --- |
| 胸 | 上胸 / 中下胸 | pectoralis_major（clavicular / sternocostal 头） |
| 背 | 上背 / 中背 / 下背 / 竖脊 | latissimus_dorsi / rhomboids / trapezius / erector_spinae |
| 腿 | 股四头 / 腘绳 / 内收 / 小腿 / 髋屈 | quadriceps / hamstrings / adductors / calves / hip_flexors |
| 肩 | 前束 / 中束 / 后束 | deltoid_anterior / deltoid_medial / deltoid_posterior |
| 前锯肌 | 整体（已最细） | serratus_anterior（外加在胸肩动作里） |
| 斜方肌 | 上束 / 中束 / 下束 | trapezius（按动作名启发式） |
| 二头 | 长头 / 短头 | biceps（按动作名启发式） |
| 三头 | 长头 / 外侧头 / 内侧头 | triceps |
| 小腿 | 腓肠 / 比目鱼 | calves / soleus |
| 前臂 | 整体 | forearms |
| 颈部 | 颈屈 / 颈伸 | neck |
| 臀部 | 臀大 / 臀中 | gluteus_maximus / gluteus_medius |
| 功能性 | 整体 | （含 cat=cardio/plyometric/balance 等） |
| 核心稳定 | 抗伸展 / 抗旋转 / 抗侧屈 | core（按动作名启发式） |
| 腹部 | 腹直 / 腹斜 / 腹横 | rectus_abdominis / obliques / transverse_abdominis |
| 拉伸 | 上肢 / 下肢 / 躯干 | stretch（按 cat + 部位启发式） |

> 二级分类当前由 `classifyExercise(ex)` 在运行时按 `primary[]` 主肌与动作名启发式打标；空值时归到一级"全部"。

### 4.3 UI 行为

- 默认：所有一级折叠
- 点击一级 → 展开该一级的二级子项；二级子项点击 → 选中并过滤该二级动作；再次点击一级 → 切换过滤回该一级全部并折叠子项
- 一级计数 = 该一级下所有动作总和；二级计数 = 子集
